# Mar Shop Presentes — protótipo

Vitrine-conceito responsiva para Mar Shop Presentes, Tatuapé/SP, com três estruturas: Casa (editorial), Achados (galeria visual por ambiente) e Guia (escolha por ocasião). O seletor no topo troca a organização da página.

**Demonstração:** https://oluisvi.github.io/mar-shop-presentes-prototipo/

As categorias e itens são referências de mercado para demonstrar a navegação. O catálogo, os produtos atuais, estoque e preços não foram confirmados. As fotos locais são imagens ilustrativas sob Unsplash License e não representam estoque da loja. Confirmar conteúdo e imagens autorizadas antes de publicação oficial.
